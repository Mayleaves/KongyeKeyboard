# 空叶键盘 3.0.8

- 展开候选按拼音条和四列候选排列；右侧顶部收起，下方依次删除、上翻、下翻、词/字，与四行候选对齐。
- 手写顶部集中放置撤回、重做、重写，右侧仅保留等大的删除、空格、回车；书写区留出独立空间。
- 拼音行删除“全部”按钮，支持左右滑动查看拼音；再次点击选中的拼音可取消筛选。
- 英文词被识别为首选时，上方显示完整英文输入，不再插入拼音分词符。
- 展开候选保留原候选栏的顺序，不再按词长重新分组；上方只显示待选拼音。

- 离线资源分为内置资源、可选增强资源、翻译与备用识别；基础拼音和约 7 MB 的手写模型内置。
- 翻译语言包和备用手写模型统一提供下载、状态和删除入口；已下载的其他翻译语言包也会列出。
- 打开键盘及启用候选翻译不再自动下载语言包；缺少资源时提示到离线资源下载。

- 首页搜索后手势返回会收起键盘、清空搜索并恢复完整菜单，不直接退出首页；从功能页返回仍保留搜索结果。
- 多音字按本次输入匹配读音，精确拼音候选优先于模糊音候选，避免“重”的 chóng 读音被默认读音筛掉。
- 使用完整拼音读音数据补充生僻字候选，展开候选不再截断为前 120 项。
- v/u 模糊音支持误按键位的替代，如 shv 找“书”、lv 找“路”，与拼音纠错开关独立。
- 手写每次只识别一个字，不在识别候选中插入词组；新增笔画撤回、重做，展开再收起候选时保留笔迹。
- 内置小型笔迹识别模型，无需另行下载；生僻字结构识别候选提前显示。
- 剪贴板垃圾桶清空当前分类的全部内容，包含该分类下的置顶内容；二次点击确认，其他分类独有内容保留。
- 手写补充通用汉字部件结构识别，并结合笔画模板和文字识别，减少模型字集不足造成的生僻字遗漏。
- 每次重新打开剪贴板默认显示“全部”；分类切换直接显示，不再截图并覆盖过渡动画。
- 剪贴板只创建可见卡片，滚动时复用，不再一次创建全部历史记录；右下角入口直接显示，不播放入场动画。
- 打开剪贴板后重新读取系统内容，补收键盘隐藏期间已经同步到手机的复制内容；图片导入移到后台。
- 键盘自身复制后，不再暂停接收其他复制事件，避免漏掉紧接着发生的外部复制。
- 粘贴保留原文，不套用成对符号、标点补空格或中英文补空格规则。
- UU 远程输入不再请求无效的全文快照，减少文本提交前的等待；跨设备剪贴板同步仍需远程软件支持并开启。
