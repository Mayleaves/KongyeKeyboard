# 空叶键盘 4.1.8

- 触控按几何距离和候选热区判断，过滤明显横向误滑与异常大面积接触；保留上下滑、滑行和空格光标手势。
- 双指快打不再在第二指按下时提前提交第一指，并在候选刷新后保留另一指的按压和输入顺序。
- 新增按键与手势中的触控校准，主动校准后可启用偏移补偿，支持清空与衰减；边界拼音参考可单独开启。
- 拼音诊断区分原始输入、手动隔音符和自动显示边界；保留连续手动隔音符。

- 修复悬浮键盘重置大小后四角标记停留在旧位置的问题，四角和触摸区域跟随键盘实际尺寸同步更新。

- 缩小悬浮键盘右下角的重置图标，保留原点击范围。

- 修复全屏手写仍按隐藏的普通键盘高度占位的问题：应用输入框紧贴底部工具栏，灰色书写层只覆盖应用。

- 手写左上角展开按钮改为小号浅灰色角标，加粗线条以便辨认。
- 手写右侧删除、撤销、重做、空格、回车各自独立成键，统一间距与高度。
- 全屏手写底部六个操作按钮等宽，独立圆角，统一使用回车键的底色。
- 悬浮调节中的重置改为右下角图标，重新绘制连贯的回转箭头与均匀圆弧。
- 灰条轻触即可进入移动状态，短划、长按拖动和调节状态下的再次拖动均可直接移动。
- 悬浮缩放改为四角独立弧形标记，弹出与淡出过渡；只有角标附近可以缩放，重置大小时保留位置。
- 保留灰色全屏手写与候选拼音逐段选择。

从此版本开始进行后续测试。沿用原有签名，可覆盖安装并保留设置和个人数据。
