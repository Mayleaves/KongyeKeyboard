# 空叶键盘 3.0.3

- 修复键盘区域左右边缘占用系统返回手势的问题。
- 键盘布局支持横竖屏标签及左右滑动，可分别保存中文键位和正常、分体、悬浮键盘；关闭分别设置后共用一套选择。
- 取消按远程应用自动悬浮；工具栏切换与键盘调节按当前屏幕方向保存。单手、分体和悬浮选项按所选形态显示，保留各自设置。
- 备份与恢复固定顶部恢复默认设置，其余操作、提示和备份内容在本地与 WebDAV 页面间左右切换。
- 本地和云端备份支持查看、恢复及确认删除；恢复前展示备份时间、版本和内容。
- 本地与 WebDAV 操作提示独立保存、独立关闭，折叠服务器配置后保留结果，提示出现和关闭使用平滑过渡。
- 坚果云上传自动准备应用备份目录，服务器配置不再要求填写应用目录名；密码使用黑点显示。
- WebDAV 支持仅手动、每天、每周及每 30 天备份，默认仅手动；自动备份在联网且手机空闲时执行，沿用所选内容。
- 连接测试明确区分目录读取与上传权限，保留具体操作结果，避免旧提示与新结果混淆。
- 短信自动复制补充「权限管理 → 写入剪贴板 → 始终允许」指引，统一短信和后台复制权限入口，避免将系统静默拦截误判为复制成功。
- 去掉打字统计称号前的铅笔图标，分享图片同步调整。
