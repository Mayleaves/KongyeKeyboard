# 空叶键盘 4.0.0

- 设置界面恢复系统标准尺寸，修正示例图裁切和比例不一致。
- 每段拼音上屏后收回放大的拼音气泡。
- 拼音显示保留歧义路径，按新输入重新判断音节边界，遵守手动隔音符。
- 对照 Fcitx/libime、Rime 核对音节切分，新增全音节、歧义输入和长句验证。
- 开发诊断可查看原始输入、音节图和最终读音。
- 修正混合简拼、拼写纠错与模糊音的候选匹配，并显示对应纠错标记。
- 快速输入时保留按键原始串，修正候选栏首字母闪动及部分常用短语排序。
- 用户学习仅记录主动选择的非首位候选，兼容旧记录并限制保留数量；修正单字母匹配到个人长词的问题。
- 主题预览按实际键盘比例显示，压缩候选读音、翻译选项中的空白。
- 悬浮键盘关闭后保留布局，拼音显示在标题栏内；横竖屏分别记住键盘尺寸和留白调整。
- 修正部分桌面文件夹名称输入框的退格兼容性。
- 切换皮肤时原位更新配色并保留滚动位置，避免面板重建造成闪动。
- 合并重复的灰色皮肤，保留动态配色；除“空叶”外，皮肤名称统一为四个字。
