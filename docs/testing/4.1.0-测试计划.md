起始日期：2026-11-26。首个测试版本：4.1.0，versionCode 61。每日计划时间：北京时间 20:00，任务附在当前聊天；首轮结束后继续按七类专项轮换。

## 数据集与使用边界

| 数据 | 数量 | 用途 |
| --- | ---: | --- |
| 训练/开发集 | 105 | 调试切分、匹配和排序规则，产生新的开发用例 |
| 验证集 | 71 | 检查候选覆盖、选择修改方案；不能反复修改标签迎合结果 |
| 冻结测试集 | 75 | 保留独立的词族，建立和比较版本基线；不作为每日调词频素材 |
| 既有回归集 | 20 | 保留已看过的案例及隔音符等历史修复证据 |

样本位于 `app/src/androidTest/assets/pinyin41/`；`manifest.json` 保存数量与 SHA256。`tools/pinyin41/corpus.py --check` 检查词族、较长输入的跨集合重复、错拼操作标签及冻结文件摘要。短声母简拼可以对应不同词族，不能把语言本身的歧义误判成相同样本。

“训练集”指规则/排序开发样本，不表示已经训练神经网络或重新训练 libime/Rime 的模型。所有内容是自编合成样本，不来自用户私人输入，不是公开权威评测，也不能据此宣称未知用户场景的准确率。

每个词族的全拼、简拼、混合输入、隔音符、模糊音和纠错变体留在同一个集合。测试集在首次基线后保持冻结；如果以后依据其中的失败进行调参，应标记为已暴露案例，并在下一版冻结集补充未用于开发的新词族，旧版本保留历史，不改标签掩盖失败。

## 每日共同检查

1. 先读项目 AGENTS.md，检查已有改动、应用版本、数据摘要和可用设备。保留“半透明效果”命名及原有外观，不重新加入撤销的玻璃光效。
2. 只有源码、版本或测试包发生变化时才需要重新构建；通过指定的 Android Build Shell 使用 E 盘缓存与临时目录。构建本身不启动模拟器。
3. 优先复用现有专用模拟器。只有做设备端检查且没有可复用设备时才运行指定脚本，以默认 `-no-window` 启动；只有需要用户查看或手动操作时使用 `--visible`。
4. 引擎批量查询可在连接的真机上运行；学习、界面和触控专项优先专用模拟器。脚本在真机上自动跳过会操作界面或改动学习夹具的专项，不把跳过写成通过。
5. 运行旧 20 条回归、当日验证集及相应专项。记录版本、APK 摘要、设备/API、数据集摘要、实际候选及读音、完整消费覆盖、重复候选、开关泄漏和异常。
6. 分别记录首批回调与完整查询 p50/p95；它们不是按键到屏幕的端到端延迟。触控专项另测原始字母完整性、双指顺序、界面帧和实际候选到达时间。
7. 失败先分类为解析/边界、候选覆盖、重排、开关或学习问题。先创建最小开发复现，再修复通用规则；不为固定测试串增加专用首选，不全局删除生僻字。
8. 同音常用词前三顺序只作参考；低频但读音合法的词不直接判错。规则错误、排名待评审、未测、设备不可用分别报告。设备不可用时仍做数据审计并记录缺项。
9. 使用独立测试内容，不发送消息，不输入真实密码或短信，不清空应用数据。每次候选批量检查设置与个人学习文件是否保持不变。
10. 报告写入 `build/pinyin41/YYYY-MM-DD/<运行编号>/`，汇总保留 `summary.json`、`summary.md` 和原始日志，`latest.json` 指向最新一次。失败也要保留证据；未获新指令不上传 GitHub 或发布发行版。

## 可执行入口

```powershell
python -X utf8 tools/pinyin41/corpus.py --check
adb devices -l
# 首轮（显式填写已确认的序列号）：
python -X utf8 tools/pinyin41/run_daily.py --serial <序列号> --build --install --splits train validation test --modes pinyin-adversarial pinyin-400
# 日常引擎检查（已有最新测试包时不重复构建安装）：
python -X utf8 tools/pinyin41/run_daily.py --serial <序列号> --splits validation --modes pinyin-adversarial pinyin-400
# 在专用模拟器上的纠错专项：
python -X utf8 tools/pinyin41/run_daily.py --serial <模拟器序列号> --splits validation --modes correction-switches
# 12 组模糊音逐组双向关闭/开启/再关闭，分别检查全拼及简拼模式（专用模拟器）：
python -X utf8 tools/pinyin41/run_daily.py --serial <模拟器序列号> --splits --modes fuzzy-switches
# 4.1.1 起的候选拼音交互专项（逐段选择、下划线、撤销及旧分词行为）：
python -X utf8 tools/pinyin41/run_daily.py --serial <模拟器序列号> --splits --modes candidate-pinyin-selection candidate-mode partial-delete
# 4.1.2 起的手写触控与全屏专项（专用模拟器，独立测试输入框）：
python -X utf8 tools/pinyin41/run_daily.py --serial <模拟器序列号> --splits --modes handwriting-touch
# 4.1.8 起的按键触控/主动校准、实际中英文滑行与光标专项（先在专用模拟器选中空叶）：
python -X utf8 tools/pinyin41/run_daily.py --serial <模拟器序列号> --splits --modes touch-recognition punctuation-flicks live-240
# 悬浮布局、灰条轻触/短划/长按移动、四角缩放/重置与手写布局专项：
python -X utf8 tools/pinyin41/run_daily.py --serial <模拟器序列号> --splits --modes floating-layout-live-400 handwriting-touch
```
