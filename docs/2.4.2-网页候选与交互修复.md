# 空叶键盘 2.4.2 本地审核记录

基于 2.4.1，版本号 2.4.2，versionCode 34。源码未提交、未推送；审核后再发布。

## 修改

- 网页自动填充候选与普通候选共享固定高度容器。覆盖层的 MATCH_PARENT 不再参与无界高度计算，避免把键盘撑满网页。
- 长候选气泡按实际换行后最宽一行收紧宽度，右边贴齐键盘边缘，保持半透明、上圆角下直角；只在打字界面显示，点击可输入完整候选。
- 拼音气泡固定预留顶部空间；出现或消失交换箭头不会改变气泡高度。交换箭头和错误波浪线同为 1.1 dp 线宽。展开编辑时光标每 500 ms 闪烁，收起后隐藏。
- 26 键上下滑清空仅作用于当前中文或英文。自定义符号输入后自动保存；编辑功能选择后立即预览，点击“保存”才应用。
- 右下角剪贴板在点击时立即切换，清理尚未结束的旧界面遮盖动画。可见图片缩略图后台解码，最长边不超过 512 px；缓存限制 4 MiB，离屏和关闭时释放视图持有的图片。
- 普通话、四川话、手写、整句输入和标点模型继续内置，功能未删减。

## 真机验证

设备：一加 PHK110，Android 16；2026-11-14。

12 组测试通过：输入分词与候选、实际触摸与滑行、正常设置入口、候选网格与手势、界面切换、组合输入、密码隐私与流程、本地编辑、横屏编辑、剪贴板分类切换、浏览器自动填充、跨应用账号关联管理。

- 在真实 IME 窗口检查长候选气泡贴右、展开与收起、点击输入，以及拼音纠错提示的固定高度和闪烁光标。
- 在正常设置入口检查功能预览不提前保存、保存后生效、符号自动保存、中文清空保留英文映射、重置恢复默认。
- 在点击右下角剪贴板的同一次处理内检查面板已显示，且旧键盘截图不再覆盖面板。
- 使用独立合成图片检查延迟解码、缩略尺寸上限及视图移除后的图片释放。
- Via、X 浏览器、Chrome 的登录与注册表单均显示正常的系统填充候选及键盘；账号/密码框来回切换累计观察 727 帧，未丢失键盘或发生位移。候选容器高度等于普通候选栏。
- 网页仅检查布局、切换和系统“更多密码”入口，未选择个人账号、未提交表单。
- 跨应用关联操作使用独立假数据，移除当前页面关联保留账号本身。

构建与 lint 检查通过（无 Error/Fatal）。最终安装 APK 与打包 APK 通过 SHA-256 对照。
