# v3.0.0 轻量资源与设置预览

基础 Fcitx/libime 解码资源与 Rime 词典继续内置，保证初次安装可打字。离线扩展模型从 APK 移至应用内「离线资源」。`resource-packs.json` 记录固定源、字节数、SHA-256 与安装位置。Gradle 的 lightAssets 任务不改动上游原始输入，仅过滤大型模型并生成不含 gram 的基础 Rime 压缩包。

下载在独立线程执行。取消保留 .part 文件，续传校验 Content-Range，服务器不支持续传时重新下载。完成后校验大小和 SHA-256，再原子安装；模型不可读取半成品。HTTPS 下载限制、空间检查、网络失败与重试均有状态反馈。升级保留已验证旧资源、整句模型与学习记录。旧的 418071596 字节整句模型仍可用；新下载通过 GitHub 固定资源编号定位 407160876 字节模型，避免 LTS 链接随更新漂移。

基础拼音、英文与基础备用手写可直接使用。普通话实时模型、普通话可选精校、四川话、精细语音标点、神经手写、离线润色分别下载。未装精细标点模型时，仅为听写补充基础句末句号；下载后用 CT Transformer。翻译与数字墨水仍使用 ML Kit 的语言模型管理。

全局显示键盘按钮打开临时输入浮层，实际使用本应用 IME。该输入框禁止自动填充与个性化学习，不写入输入统计，关闭不保存内容。关闭浮层回到原设置页。设置切页采用 110ms 覆盖动画，前进由新页覆盖旧页，返回移开当前页。设置示例只使用固定虚构内容，不使用用户的正文或剪贴板，不标注未经测量的性能数据。开关始终同时展示左侧关闭、右侧开启；当前状态高亮，另一侧整体去色灰显。多选项固定展示对应的对比面板。键盘形态的开启设置集中在「键盘布局」，尺寸调整页只保留三种实时预览和尺寸参数，重置不改变开启状态。

便签退格在富文本段落边界使用原生退格按键；标准文本编辑器在明确的换行处使用 UTF-16 删字接口，兼容横屏输入连接忽略模拟按键的问题，兼容返回成功但没有合并段落的富文本输入连接；ColorOS/OPlus/OnePlus 系统便签使用其原生退格处理。真实一加便签仍需在对应设备复核；协议模拟和实际多行输入框用于回归。
