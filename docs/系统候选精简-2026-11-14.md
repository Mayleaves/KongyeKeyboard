# 系统候选与重复密码入口精简

用户要求保留键盘的系统候选，移除输入框下方浮动密码框、键盘额外的「🔑 更多」及「密码空间」面板入口，系统「更多密码」去除搜索副标题，并修正打开密码选择页时的抖动。

本任务仅在当前仓库工作上调整：

- KongyeIME.showInline 不再添加额外搜索 TextView，保留系统 InlineContentView 与关闭按钮。
- onCreateInlineSuggestionsRequest 始终提供 Android 11+ 的内联通道；原下拉显示开关移除，设置说明改为系统候选入口。
- VaultFill.actions 不再提供「🔑 密码空间」面板入口；保留原有生成、复用、保存逻辑。
- 对应等待条件的 VaultRegression 改为检查 available 状态，明确断言已移除的入口不会重现。
- AutofillTransitionRegression 新增断言：无独立更多 / 密码空间 TextView、无 Autofill UI 浮窗；点击最后一项系统内联候选打开空叶文档的搜索页，采样标题位置，确认不移动。

仓库在本任务开始时已由另一任务升级至 2.4.0 / code 32，保留版本与其他改动，不回退至 2.3.x，也不误提交全部工作。
