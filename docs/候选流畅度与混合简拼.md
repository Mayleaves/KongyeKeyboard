# 候选流畅度与混合简拼

本文保留 2.2.0 / 2.2.1 的开发与验收记录。2.2.2 默认 26 键已改用 Fcitx5 / libime，最新范围和结果见 [成熟引擎说明](Fcitx5-成熟引擎接入.md)。

## 本轮调整

- 基础候选先送到界面，纠错与模糊音备选完成后补充；同一显示帧只绘制最新结果。
- 连续输入时检查查询代次，过时结果不再继续做额外纠错，不覆盖新输入；已取消的排队任务及时移除。
- 完整拼写匹配时不再无条件追加纠错查询；简拼优先保留原生词典排序，同时继续提供相邻键、漏打、多打及颠倒字母的备选路径。
- 多声母混合简拼中，尝试用原生词典和已学习词的高频声母词展开前缀，再让 Rime 解码全句；至少要求两个完整尾部音节提供上下文。只接受完整覆盖且拼写一致的原生结果，不添加专门的例词覆盖。完整词条及两声母短简拼的连贯整句保留原排序。
- 中文键盘新增“候选区显示拼音”开关，默认关闭；只控制候选词旁的读音，不影响上方拼音条、手写声调及多音字。输入中的上方拼音条始终保留。
- 停靠键盘的透明度不再改变应用避让高度。悬浮模式仍覆盖应用。透明处能否看到文档内容取决于目标应用实际是否绘制该区域。

## 开源方案调研（2026-11-11）

- [Google Input Tools](https://github.com/google/google-input-tools)：Google 官方旧输入工具，包含 Chromium OS 的 JavaScript 中文解码器及 Windows 拼音输入法；仓库已于 2022-12-29 归档。这并非当前 Android Gboard 的中文引擎和模型。
- [Mozc](https://github.com/google/mozc)：Google 开源日文输入法，不提供中文拼音解码。
- [Fcitx5 Android](https://github.com/fcitx5-android/fcitx5-android)：成熟的 Android 输入法框架移植。
- [libime](https://github.com/fcitx/libime)：可供进一步比较的中文整句解码核心，支持拼音与纠错；切换需适配原生依赖、候选消耗边界、学习与各布局，不能只换词库文件。
- 本轮未找到可直接接入的讯飞或当前 Gboard 中文引擎官方开源实现。GitHub 上的修改版 APK、主题和调用示例不能视为引擎源码。

本轮继续使用已接入并可离线运行的 Rime，先修复可复现的候选管线问题；不宣称它等同于商业输入法的全部排序效果。

## 回归重点

`wsmyoudianka → 为什么有点卡`、`wsmzhememan → 为什么这么慢`；已有正确整句 `hxbuzhidao → 好像不知道` 不被高频简拼前缀覆盖。保留此前整句、错拼、九键、14 键、词组消耗边界及表情位置检查。测量首次基础候选与完整候选耗时，并验证过时查询取消。

设备与实际结果另存本机审核记录；构建成功不等于真机流畅度验证完成。发布须由用户审核后另行授权。

本轮 Release/lint 已通过。索尼 A202SO Android 14 上，使用发布 DEX 和原生库的独立进程回归通过；临时词库与已安装应用分离，结束后清理。23 组整句及既有错拼、布局、表情位置与查询取消检查通过，热查询基础候选为 1–10 毫秒。

最终审核包已安装并核对 SHA256。真实软键触摸后立即按空格的五项检查通过：`wsmyoudianka`、`nhaoa`、`xianzaidejianpanjvnanyong`、`wsmzhememan`，以及 `nihaox` 删除末字母后选词。输入阶段每键间隔 20 毫秒，加上系统注入等待约每秒 18–20 键；从最后一次触摸到读取确认上屏约 102–121 毫秒，含触摸注入和无障碍读取开销，不代表纯引擎延迟。

该轮 131 帧中位耗时 7 毫秒、P90 15 毫秒、P95 20 毫秒；仍有 8 帧被系统标为卡顿，不宣称完全消除。拼音开关打开、关闭已验证。透明度 100% 与 58% 时，底部聊天测试输入框同为 `[30,1410][1050,1590]`，保持在工具栏上方；已恢复原来的 100% 与默认隐藏拼音。

早期测试框没有禁止学习，误学了“为生命这么慢”；已通过原生删除候选接口只移除这条本次 QA 产生的记录，没有清空词库。测试框现设置 `IME_FLAG_NO_PERSONALIZED_LEARNING`，随后五项真实输入复测全部通过。临时诊断代码及测试程序已移除。

用户随后明确委托自行测试，通过后打包。本地 2.2.0 打包前再次通过 Release/lint、原生拼音、拼音编辑、面板动画、本地编辑、横屏与密码隐私回归，并再次完成五项真实快速输入，最后按键到读取确认上屏为 92–119 毫秒（含系统注入和读取开销）。用户已授权本地打包；未提交或上传 GitHub。

键盘调节面板移除透明度滑条和值，保留底部留白及尺寸、悬浮、分体操作。调节的重置和确认不再修改全局外观透明度。
