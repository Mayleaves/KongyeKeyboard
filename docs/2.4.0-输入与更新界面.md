# 2.4.0 输入与更新界面

本地开发审核版本，尚未提交或上传 GitHub。沿用 2.3.1 的浏览器输入框切换及系统工具栏自动填充修复。

## 候选气泡

只有普通打字界面的首候选文字超过可用宽度时，才在右上显示全文；点击全文气泡与点击第一候选走相同的消费、振动、学习和隐私规则。气泡触摸区域纳入输入法窗口的可触摸区。展开候选页不显示此气泡，继续保留 1–4 格的长词排版。

## 拼音标记

基于候选读音和实际输入的对齐结果，将错误音节整体保留：例如 `woianu` 对应“我爱你”时显示 `wo'ia'nu`。只改变分隔位置，不替换用户字母；交换箭头位于 `ia` 上方，错按字母 `u` 下方为波浪线，交换字母不再重复画波浪线。普通输入的稳定追加分隔仍保留。音节修正后的分组在下一次查询等待期间保持，避免闪回临时拆分。

## 按键与滑行

- 26 键设置页显示真实角标；选键、编辑草稿和保存后的映射均实时反映到键帽。中文/英文独立保存，清空所有上下滑同时禁用两个语言的映射；恢复默认按语言进行，不影响点击字母。
- 滑行输入默认关闭。开启后，跨键移动以有界频率查询离线词典，松手前即可更新候选；中文显示带下划线的拼音，英文不显示拼音条。取消、离开和新查询使旧结果失效，轨迹不保存、不上传。
- 常规页面、工具面板、分类及条带的切换统一为 180 毫秒，和中英切换相同。开屏 Logo、拖动反馈并非页面切换，保留原节奏。

## 剪贴板

粘贴后更新该条的最近使用时间并移到最前，文字、图片都适用。置顶属性、自定义分类及长期存储不改变，不会因重排复制出重复条目。

## 更新与应用界面

设置首页重新分组为输入、外观、工具与隐私、关于与帮助；顶部增加“试一试”和“自定义按键”。使用前的启用输入法、选择输入法与通知入口继续保留。

更新内容由 Markwon 4.6.2 / CommonMark 0.13.0 原生渲染，支持标题、粗体、删除线、代码、列表、任务列表、表格和链接；不通过 WebView 执行脚本，不自动加载远程图片。仅用户主动点击 http/https/mailto 链接时交给系统打开。

历史版本从 GitHub Releases 读取并缓存，同时内置已发布记录和本机版本说明；历史与详情均可离线查看。第三方固定 URL、SHA256 和许可证记录在 markdown-sources.json / assets/licenses；可用 tools/fetch_markdown.py 恢复构建依赖。

## 密码空间的解释与调整

键盘工具栏保留 Android 系统候选，独立密码空间入口已移除。当前填充和关联由空叶文档的自动填充服务处理，成功返回填充结果时按 App 或网站保存关联。该结果只说明已填入，不能确认是否登录成功。

误选 A 后仍可改选 B。若 A 留在推荐中，可到空叶文档 → 密码空间 → A 的条目详情 → 已用于，删除对应 App 关联。网页关联通过编辑条目的「网址」更正。

## 验证

发布构建、三种 ABI 安装包完整性及 Lint 已通过。已在一加独立输入框验证：长候选气泡点击提交与展开页隐藏；错误拼音分组与标记；中英文滑行在松手前更新；剪贴板重排保留分类和置顶。现有拼音、手写、流式语音、编辑、横屏及切换回归也已通过。

已核对键帽预览和更新历史详情在一加上的实际显示。所有测试仅使用虚构输入和隔离状态，不提交真实表单、不读取正式密码。
