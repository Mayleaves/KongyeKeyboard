# 空叶文档输入兼容待改

2026-11-10 使用空叶键盘 1.5.8，在空叶文档原版后端的隔离测试文档中验证。正式文档应用未修改。

已通过键盘侧修复：
- 一次长按删除连续跨过两个段落边界，删完三段，无需松开重按。
- 实际输入标点后上划撤回，连续四轮均还原文字与原光标位置。

仍需文档侧修改：
1. `EditorState.kt:402` 将输入连接产生的非折叠选区转为 `selection.set`，没有保留键盘来源。
2. `EditorScreen.kt:257` 发现 `selection.active && !selection.fromKeyboard` 后会主动清焦点、隐藏键盘。因此编辑面板第一次扩选一字后就收起，后续方向键无法使用。应识别键盘扩选来源，保留输入连接与键盘，并支持连续、跨段扩选。
3. `DocumentInput.kt:66` 将覆盖当前段落的 `setSelection` 猜测为全文全选，可能误伤局部选区；应使用明确的全选命令，普通选区严格尊重范围。

实机复现：编辑 → 选择 → 右，选中一字后 `selection.active=true`、`fromKeyboard=false`，键盘被隐藏。
这些问题不能靠键盘强行重新弹出解决，否则会与文档的焦点管理互相争抢。

原型和测试源保存在本机 KongyeDocs/build/proposed-input-fixes，供后续处理。原型未发布、未覆盖安装正式文档。
