# 2.3.0 候选与手势

本地审核版本，尚未上传 GitHub。公开版本仍为 2.2.2。

## 候选与拼音

- 展开候选保持四列基准，按文字实际宽度占 1–4 格，不再把长句缩成很小的字；超过四格的文字在末尾省略，右上预览显示全文，较长全文可以滚动。
- 删除“超过四个字就弹气泡”规则，未截断的候选不弹全文气泡。
- 始终保留原生首选在最前面，其余文字按长词、三字、两字、单字分层；符号/颜文字与原始拼写随后显示。展开面板继续提供原生词典中匹配的三字、两字、单字词；筛选在原面板内更新，不重播整面板淡入。右侧删除长按连续退格，保留按钮实例，不随每次候选刷新重建。
- 主删除键在组字时长按仅清空拼音与待上屏选词；无拼音时保留按住连删正文。候选区删除仍逐字删拼音。
- 原始输入和既有分隔位置保留；相邻字母倒序用弧线、错字用波浪线提示。通用音节约束仅为无效拼写生成有界倒序备选，文字由 libime 解码；不加入例句首选词覆盖。使用邻键、倒序与增删字母的加权距离保护原生整句；已有合理纠错时跳过重复回放。普通打字走主要候选路径，展开时才补查三字、两字、单字词，避免把扩展查询的开销加到每个按键。

## 26 键上下滑

“按键与手势 → 26 键上下滑”可逐键选择中文/英文、上滑/下滑，保存符号或编辑功能。中文和英文分别保存，分别重置。默认符号按本轮截图设置。

编辑功能包括撤销、重做、复制、剪切、粘贴、全选、选择、四向移动、段首、段尾、删除、换行、清空；密码框沿用原有复制限制。UU 需要本地编辑预览的动作仍进入本次输入编辑流程。

## 离线滑行输入

“按键与手势 → 滑行输入”独立开启/关闭，默认关闭。仅用于 26 键中文拼音词语和英文单词，九键、14 键、密码框关闭滑行；关闭时保留原来的轻点与上下滑符号。

手指跨键滑动后显示细轨迹，松手用端点、粗形状和动态时间规整在离线词典中检索拼写。中文随后由 libime 给出文字候选，英文显示单词候选，支持首字母大写与大写锁定，选词或空格上屏。不是商业输入法滑行模型，不承诺任意整段轨迹均能正确识别。

中文复用已有辅助拼音词库；英文为雾凇固定版本的 21,212 个单词，来源、SHA256 见 glide-sources.json，提取脚本为 tools/build_glide_dictionary.py。词典只在开启后预热/识别时加载，闲置后释放，不阻塞主线程释放缓存。不保存或上传手指轨迹。

## 新短信验证码

在“剪贴板”主动开启。只声明 RECEIVE_SMS，不申请 READ_SMS，也没有通知读取服务；只处理系统新短信广播，不扫描收件箱或通知。识别带验证码上下文的 4–8 位数字/字母数字组合，排除没有验证码语义的订单号、电话号码等。

验证码以敏感内容标记复制到系统剪贴板，同时携带随机标记和到期时间。历史剪贴板采集跳过该标记。到期仅清除仍带本次随机标记的剪贴板，不影响用户后来复制的其他内容。私有偏好只存随机标记和时间，不存验证码或短信正文。

锁屏时保留保护，不直接复制；尚未到期的验证码仅在当前进程内存等待解锁，超时丢弃，进程被系统终止也不保留。系统可能提前清空敏感剪贴板；进程定时器及系统非精确闹钟配合处理 10 分钟到期，设备休眠可能延迟后台回调。解锁或重新使用键盘时再次检查到期。

## 验证

索尼 A202SO / Android 14 上，Release 构建、lint（0 错误）与候选/手势/验证码合成检查通过；原生整句、手写语音共存、编辑/横屏及密码隐私回归通过。真实软键快速输入六项及两种长按删除通过，确认已上屏正文保留。中文、英文及大写锁定滑行实际触摸检查通过，结束后恢复中文与滑行默认关闭。跨格排版、省略全文气泡、错字/倒序标记和设置页面已截图核对。测试使用公开词典、虚构短信与独立输入框，不读取用户短信或正式文档。短信权限须用户自己授权；目前不以真实运营商短信到达替代或冒充合成数据检查。
