# 2.3.1 浏览器填充与输入框切换

用户已明确授权直接修改并在一加 PHK110（Android 16，525114fb）测试。版本 2.3.1 / code 31；沿用签名覆盖安装，不清除设置、词库或剪贴板。

## 修改

1. KongyeIME.onStartInputView 调用 applySkin(animateKeys=false)，applySkin 把此参数传至 render。切换网页账号、密码输入框时更新布局，不重播 NativeMotion.pulse 的 3dp 位移动画；键盘内主动切换布局保留默认动画。
2. res/xml/method.xml 声明 android:supportsInlineSuggestions=true。原来已实现 InlineSuggestionsRequest / Response，但缺失能力声明，系统默认 false，会退回夺取浏览器焦点的下拉候选。
3. showInline 保留系统 InlineSuggestion.inflate 给定的宽高。此前覆盖成 WRAP_CONTENT，InlineContentView 没有固有宽度，会被压为零宽，导致真实候选不可见。

保留现有「自动填充候选显示在工具栏」设置；未强行更改用户的候选显示偏好。测试设备此项开启，系统候选显示在工具栏，避免 Via / X 的下拉窗口焦点变化触发浏览器隐藏键盘。
