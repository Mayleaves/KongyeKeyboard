# 输入核心升级 2.1.0

## 问题和实现

旧拼音核心只做词条前缀查询和贪心拼接，不能稳定生成长句；单字鼻音词条还可能压过常用声母候选。
2.1.0 接入成熟 Rime 原生核心、雾凇完整原始词库及万象 LTS 整句模型，保留空叶原有皮肤、工具、密码填充和编辑交互。

Rime 管理词典、词频、简拼、全拼混输、自动音节分隔及整句组合；前端通过原生候选的实际消耗边界选词，不能把选择前半句误当成整句上屏。
14 键和九键使用映射后的 Rime 拼写图，不再退回旧的小词库。
旧自造词继续迁移；只有用户开启学习且输入框允许时，选词才进入 Rime 学习记录。
密码框直接输入，绕过拼音解码、学习和缓存；离开输入框清除查询缓存和未提交状态。

纠错通过 Rime 拼写图表达漏字、多字、邻键及倒序；常规图与纠错图分开，防止把正常整句改成无关词。
短错拼存在多个合理解释时仍需选择候选，本版不承诺与商业输入法的所有排序一致。

## 手写和语音

- 手写：ochwpro 开源 Transformer 笔迹模型（7,356 类），直接读取轨迹而不是与规整字体描边匹配；HanziLookup（9,507 字）保留作初始化失败时的离线备用。
- 注音：单字显示声调和多读音；六万常用词按词标注，例如 `银行 → yín háng`。
- 备用：已有 ML Kit 数字墨水和 OCR 保留，开源模块不可用时继续提供输入能力。
- 普通话：内置 sherpa-onnx 官方 Zipformer CTC 流式模型，按音频帧增量出字；已有大模型用于句末复核。
- 四川话：保留川渝专用 Paraformer，未用普通话小模型替换方言识别。
- 麦克风只在主动开启语音后采样；预热不录音。文字继续以草稿预览，确认保留、取消恢复。

## 调研的上游实现

- [Rime](https://github.com/rime/librime)：本版实际接入。插件和词库来源见第三方说明。
- [Fcitx libime](https://github.com/fcitx/libime)：调研过整句解码和纠错实现，本版没有把代码复制进旧引擎。
- [ochwpro](https://github.com/ximeiorg/ochwpro)：本版主手写模型；原始 ONNX 权重、五维坐标特征和字符表。
- [HanziLookup](https://github.com/gugray/hanzi_lookup)：本版保留原始 WASM 作离线备用。
- [Fcitx 手写](https://github.com/fcitx/fcitx-handwriting)：调研其 Zinnia 集成；未打包。
- [sherpa-onnx Android](https://github.com/k2-fsa/sherpa-onnx/tree/master/android)：流式采样与增量识别参照其官方接口。
- [Dolphin](https://github.com/DataoceanAI/Dolphin)：官方列出四川话等方言，也有流式模型；其 Android ONNX 转换和现有 SDK 的模型类型适配尚未实测，因此本版没有宣称支持或替换现有四川话模型。

## 数据和首次启动

完整语法模型约 418MB，连同词库和各架构依赖，ARM64 包约 513 MiB、x86_64 包约 524 MiB、universal 包约 625 MiB；首次启动后台整理预编译数据约数秒，后续无需下载或重新编译。
实际手机输入和兼容升级回归已完成。原生来源、许可证与数据生成步骤均记录在仓库中。

## 本次验证记录

设备：索尼 A202SO，Android 14，arm64。使用独立测试 APK 和虚构输入，不修改正式文档或密码空间。

- Release 构建、lint：通过。
- Rime：20 组整句/常用词输入，6 组邻键、漏字、多字、倒序，以及九键、14 键、候选前缀消耗：通过。
- 真实触摸：`xianzaidejianpanjvnanyong` 在候选条显示完整句子和分词符，空格完整上屏“现在的键盘巨难用”。
- 手写：公开构造笔画“大、人、中”均出现在前五候选；真实触摸写字能显示带调多读音。`行` 有 `xíng / háng` 等读音，`银行` 为 `yín háng`。
- 普通话流式公开样本：有 8 次中间结果，最终包含“介绍”“研究”；冷启动整段处理约 2.25 秒，低于音频时长。此耗时含模型加载，不是承诺的实时首字延迟。
- 普通话及四川话高容量离线模型：安装、SHA256 与公开样本识别通过。用户本人四川话口音尚需自行试用。
- 密码隐私与流程、拼音编辑、剪贴板、本地编辑、UU 输入历史、面板不变暗、横屏编辑、语音草稿确认/取消及声波对称：通过。
- 应用内更新：大 APK 验证、错误版本/摘要拒绝、系统安装器 intent，以及从稳定发行列表选最高版本：通过。

为保留旧版本应用内升级，另准备 2.0.4 小包作为过渡：旧客户端的 GitHub latest 指向小包，新客户端从稳定发行列表找到 2.1.0。
该发布路由须在正式发布时核验；它不改变本地签名和系统安装确认。

局限：短错拼会有歧义，部分“真棒”错误变体需手动选第三到第五候选；不开云端识别，也不承诺达到讯飞、Gboard、Windows 的全部排序效果。

## 审核后确认

- 主词库替换为雾凇固定提交 `99662ba` 的完整原始表和词频，纠错不再抢占已有完整简拼词；原生查询已确认 `nhaoa` 首选“你好啊”、`budn` 首选“不懂呢”，未添加专用词条。
- 手写切换为原始 ochwpro ONNX 模型，保留声调、多音字和全部旧备用能力。公开笔画形变样本共 12 字×3 形态；它们不能代替用户本人潦草字体验。
- 语音不再在普通打字时常驻预热；关闭工具 30 秒后释放手写、语音模型，内存紧张时立即释放未使用模型；旧拼音索引在 Rime 就绪后释放，保留联想、分词和自造词。
- 提供 arm64-v8a、x86_64 和包含两者的 universal 包；不支持 32 位。所有原先内置的离线模型继续内置。
- 用户已审核并明确授权上传 GitHub，按 GPL-3.0-only 发布源码及发行版。
- 翻译语言选择以独立覆盖层上下淡入淡出，连续点按只改变该覆盖层，工具栏保持稳定；输入后自动收起。其他工具打开时关闭翻译条。
- 剪贴板分类支持左右滑动，以内容快照和新页面滑动过渡；快速切换保留最后一次目标，结束后释放快照，空分类提示不左右位移。
- 中文拼音的 emoji、符号、颜文字关联从第 5 候选开始，不改变前四个文字候选，也不进入中文词库学习。
