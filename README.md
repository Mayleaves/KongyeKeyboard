# 空叶键盘

Android 中文输入法，支持全拼、简拼、纠错、联想、自造词，以及 26 键、14 键和九键布局。

当前版本：**1.5.7**。Android 8.0 及以上，安装包面向 ARM64 设备。

## 功能

- 多套皮肤与日夜模式，支持键盘高度、振动强度、工具栏排序和悬浮键盘。
- 上下滑动输入符号，长按空格上下左右移动光标，撤销与重做。
- Emoji、颜文字、收藏；文字与图片剪贴板、自定义分类和分词。
- 中文手写按笔画识别（ML Kit 数字墨水，首次使用下载约 20MB 模型），候选显示拼音；模型下好前用离线文字识别兜底。
- 翻译输入条：选目标语言、打字或说话，译文实时显示在输入框里，点“完成”确定。ML Kit 离线翻译，首次使用需联网下载模型。
- 模糊音（z/zh、c/ch、s/sh、n/l、f/h、r/l、an/ang、en/eng、in/ing、ian/iang、uan/uang），可逐项开关。
- 纯色日夜配色；液态玻璃沿用 1.5.4 的半透明底与细描边，不使用渐变。
- 四周拖动调节键盘大小、透明度、悬浮与分体；等宽候选格及字词筛选。
- 符号、Emoji 和颜文字支持跟手左右滑动切换分类；剪贴板长按以动画覆盖工具，不改变卡片高度。
- 检查更新：从 GitHub Releases 读取最新版本。
- 语音支持普通话和四川话本机离线识别：普通话模型约 82MB，四川话专用模型约 238MB。已安装并校验模型时优先离线识别；未安装时可使用系统识别服务。语音面板支持切换方言。需在设置页手动授予麦克风权限。
- 语音文字实时预览在当前输入框，点“确定”才保留，取消恢复原选区；声波原地左右对称，随声音起伏。
- 语音进入即开始采样，冷加载期间保留开头录音；所选模型提前预热并复用，避免每次暂停重载。

功能仍在持续完善，部分皮肤和图片剪贴板的跨应用兼容性尚待完整验证。

## 安装

从仓库的 Releases 下载 APK。安装后，在应用设置中启用空叶键盘并将其选为当前输入法。

翻译首次下载需要能访问模型服务器的网络。如果一直没有进度，可点“重试”；界面会显示下载进度或系统暂停原因。

## 构建

使用 Android Studio 的 JDK 和 Android SDK，安装 SDK 37，并在本机的 `local.properties` 中配置 `sdk.dir`。本文件不提交到仓库。

首次构建先获取固定版本的离线语音引擎（脚本会校验官方 SHA256；大型二进制不提交进 Git）：

```sh
python -I tools/fetch_offline_voice.py --engine-only
```

不加 `--engine-only` 时也会预下载两套模型和公开测试样本到 `build/offline-voice/`，用于手机安装和设备端验证。模型不会打进 APK。

Windows：

```powershell
./gradlew.bat assembleRelease lintRelease
```

macOS / Linux：

```sh
./gradlew assembleRelease lintRelease
```

输出：`app/build/outputs/apk/release/app-release.apk`。

项目当前为本地分发沿用 debug 签名。首次换一台电脑构建会生成该电脑的 debug 密钥，因此不保证能直接覆盖其他电脑签名的安装包；正式分发应配置独立签名。

## 词库和引擎检查

生成后的词库已包含在源码中，日常构建不需要原始词典数据库。

重新生成时需要空叶阅读的 `dict.db`，并安装 Python 依赖：

```sh
python -m pip install -r tools/requirements.txt
python -I tools/build_lexicon.py /path/to/dict.db app/src/main/assets/lexicon.txt --chars 9000 --words 60000
python -I tools/build_lexicon.py /path/to/dict.db design/lexicon.js
python -I tools/check_lexicon.py
```

生成器使用普通话音节白名单过滤异常读音，ü 写为 v。展示页位于 `design/`。

拼音引擎与手写候选检查：

```powershell
./tools/engine_check/run.ps1
```

脚本使用 Gradle 缓存中的 Kotlin 编译器；`JAVA_HOME` 需指向 JDK，脚本中的 Android SDK 路径需按本机环境调整。Git Bash 可使用 `tools/engine_check/run.sh`。

## 1.5.0 更新

- 记忆：连着一个字一个字打出的词（如分三次打出的“夏星月”）会记成新词，之后简拼 xxy 就能出来；自造词在简拼时排前面。
- 候选区只有第一个候选有底色、都不加粗；拼音条改为实色底和淡投影。
- 上下滑出的符号移到中间时保持黑色；删除键下滑为红底“清空”、上滑为蓝底“撤回”；中文输入时大写键的分词改为图标。
- 键盘调节时不能误点按键；左右手柄改为宽度滑条和左中右位置；透明度作用到整块键盘（包括按键）。
- 液态玻璃改用系统跨窗口模糊（Android 12+），键盘后面的内容模糊透出；键帽加镜面光斑和厚度暗边。
- 数字键盘返回键和符号键互换；表情左右滑切换同一大类里的小分类；手写的重写、空格改为图标。
- 剪贴板：长按后保持两列，操作改为图标；去掉“链接”“号码”分类；复制快捷条和分词面板按钮重新设计。
- 翻译输入条简化为一行，译文直接显示在光标处；语音声波只在说话时起伏，新增离线包查询（取决于系统语音服务是否支持）。
- 长按工具栏的编辑工具可左右滑动移动光标；左下角改为收起键盘；设置页配色更素净，开屏动画不再透出设置页。

## 1.3.0 更新

- 打拼音时键盘左上角伸出拼音条，点拼音中间可以把光标移过去修改；第一个候选改为主题色底。
- 长按字母弹出小写、大写和符号，左右滑选择；空格长按可设为移动光标、连续空格或开关语音。
- 删除键下滑显示红色“清空”，上滑显示蓝色“撤回”；光标模式在空叶文档跨段时不再退出。
- 数字键盘功能键改为图标，左列符号和 @ . 空格三个键可自定义；输入 @ 后联想常见邮箱后缀。
- 符号面板改为 7 列键帽网格，底行是返回、123、可横滑分类（含“最近”）和删除；九键底行改为符号、123、加宽空格、中英、回车。
- 键盘调节：拖动顶边调高度、左右两边收窄，调透明度和底部留白。
- 颜文字分 10 类；剪贴板卡片固定四行高，长按操作改为图标，搜索时结果实时显示；分词可滑动多选。
- 手写改用数字墨水识别；语音实时出字、显示声波，可选普通话或四川话（识别服务没有四川话模型时自动改用普通话），取消或确定上屏。
- 翻译改为输入条形式，译文实时进入输入框；模糊音；液态玻璃；检查更新。

## 1.2.1 更新

- 翻译增加 25 秒超时、下载进度、暂停原因和重试恢复，防止旧请求覆盖新结果。
